# v1.1 이후 검토 목록

2026-09-24부터 새 기능은 여기에 분리한다. 일정·구현·배포를 확약한 목록이 아니다.
v1.0에는 기존 범위의 결함 수정과 승인 증거 보강만 반영한다.

- 벡터 검색·RAG와 더 복잡한 기억 정책.
- 모델 미세조정, 다중 방송 플랫폼, 게임 자동 조작.
- GUI, 상시 마이크, 자동 끼어들기, 단어별 자막 동기화.
- 병목이 입증된 경우의 문장별 합성·선행 처리·STT 모델 상주.
- 무인 장시간 운용과 자동 복구 확대.
- 별도 API 정책 검토를 전제로 한 외부 플랫폼 데이터 저장 범위 변경.

각 제안은 사용자 가치·선행 조건·자원 비용·권한/데이터 정책·회귀 시험을 따로 검토한다.
현재 남아 있는 실제 장치·방송·기억·STT 검증과 새 PC 재현은 이 목록으로 미루지 않으며 v1.0 승인 조건으로 유지한다.
