2026-09-23, 기준 `04564f1` 위 readiness 미커밋 변경. 자동 회귀 검사 완료, 실제 검증 대기.
설정은 `configs/character.yaml`의 호칭·존댓말·1~3문장·세계관·불확실성 태도·피할 표현·예시를 사용한다.
기존 로컬 설정은 덮어쓰지 않는다. 추가 필드 `unknown_facts`는 이전 설정 호환을 위해 선택 항목이지만
제공하면 비어 있지 않은 문자열이어야 한다. 알 수 없는 필드와 예시의 추가 키는 거부한다.

## 자동 검사 범위

`tests/test_character_behavior.py`는 설정 필드 검증, 프롬프트 역할 분리·4096 컨텍스트 예산,
표정 분류와 CLI 정책 주입을 검사한다. `tests/test_output_regressions.py`는 고정 출력 fixture로
역할 태그·미완성 think·구조 오류·비밀값·이메일/국내 휴대폰/주민번호 형태·명시적 모욕·반복·길이 초과를 검사한다.
사용자 입력과 대화 이력의 탐지된 비밀값·개인정보는 LLM 전송 전에 거부한다.
차단 출력은 대체 문장과 neutral을 사용한다. KoboldCpp가 `finish_reason=length`를 반환하면
잘린 답변을 발화하지 않는다. 해당 메타데이터가 없는 응답의 의미상 완결성은 보장하지 않는다.

숫자 전체를 한글로 변환하지 않고 제한된 단위·API/CPU/GPU만 풀어 쓴다. URL은 '링크',
코드는 음성에서 생략하며 원문은 화면에 남을 수 있다. 코드만 있어 음성이 비면 대체 응답을 사용한다.
음성은 화면 답변을 요약해 대체하는 기능이 아니며, 발음과 생략 후 문맥은 청취로 확인한다.

정규식·금지어는 의미 기반 안전성 검사가 아니다. 우회 표현, 모든 개인정보, 모든 모욕 및
프롬프트 공격을 탐지하지 못하며 오탐도 가능하다. 표정 규칙은 제한된 첫 문구만 인식하므로
같은 감정의 다른 문장은 neutral일 수 있다. 모델이 임의 핫키·파일·동작을 지정하는 경로는 없다.

## 실제 확인 기록

이번에는 외부 LLM 평가·합성·청취·VTS 화면 검사를 실행하지 않았다. 사용자의 기존 청취 불가와
VTS/OBS 미준비 상태를 유지한다. 완료 전에 위 질문의 말투·길이·사실 태도·발음·표정을 관측하고,
차단·중지·복귀까지 녹화로 확인한다. 자동 테스트 통과만으로 실제 캐릭터 품질 완료나 병합 가능으로 판단하지 않는다.
