# skill.md 적용 현황

2026-09-21 코드 대조 결과. 이 문서는 구현 상태를 설명하며 skill.md의 요구사항을 대체하지 않습니다.
문서 앞부분의 프로젝트 적용 기준과 0·1단계 우선 순서를 적용했습니다.
후속 단계까지 모두 구현했다는 의미가 아닙니다. 기존 구현은 재사용했고 최근 기록은
이전 `feat/conversation`의 `RecentHistory`를 가져와 현재 취소 처리와 통합했습니다.

## 남은 결정과 실제 검증

후속 전체 구현에는 방송 플랫폼, GPT-SoVITS 서버/모델/참조 음성, 오디오 장치,
VTube Studio 아바타·인증, OBS 장면, 장기 보관·삭제 범위가 필요합니다.
실제 KoboldCpp 실행 파일·GGUF 경로·출처가 아직 제공되지 않아
서로 다른 질문의 실제 응답, 추론 태그 처리, 중지 후 재시작 검증은 완료하지 못했습니다.
