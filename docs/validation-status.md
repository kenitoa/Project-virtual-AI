## 상태 정의

- **구현 전**: 해당 요구를 만족하는 기능이 아직 없다. 관련 일부 코드가 있어도 전체 요구를 완료로 간주하지 않는다.
- **자동 검증 완료**: 기준 SHA의 해당 자동 검사를 통과했다. 실제 장치가 필요 없는 범위에 한정한다.
- **실제 검증 대기**: 구현 및 자동 검사와 별개로 기준 SHA에서 실제 서버·장치·사람의 관측 증거가 필요하다.
- **실제 검증 완료**: 기준 SHA와 환경·절차·관측 결과가 기록된 실제 검증을 통과했다. 이번에는 해당 상태로 새로 판정한 기능이 없다.

실패는 상태와 별도로 기록한다. 미실행은 실패 관측이나 성공을 의미하지 않는다. 표의 병합 가능 여부는 기능별 검증 관점이며 원격 PR 병합 가능 상태를 의미하지 않는다.

현재 새로 관측된 자동 검사 실패는 **0건**이다. 표의 구현 전·미확인 항목이 남아 있으므로 전체 기능 완료나 안정 버전으로 판정하지 않는다. 원격 PR 상태·CI·병합 여부는 이번 검사 대상이 아니다.
