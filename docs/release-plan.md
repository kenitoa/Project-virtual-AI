# v1.0 완성 범위와 작업 계획

2026-09-24 갱신: [최종 승인표](release-approval.md)에 따라 **릴리스 보류**.
이제 v1.0 기능 범위를 동결하고 결함 수정·필수 검증 보강만 반영한다.
새 기능은 [v1.1 이후](post-v1-backlog.md)로 분리한다. 아래 초기 작업 공간 기록은 당시 이력이며
현재 readiness에는 여러 단계의 미커밋 코드·설정 예시 변경이 누적되어 있다.

기준일: 2026-09-23. 검증 기준은 `04564f1134dd330d77a164904190087ab59d1c23`이다. 이 커밋은 기능 검증의 출발점이며 안정 버전이나 배포 승인 버전이 아니다. 결과는 [검증 현황](validation-status.md)을 따른다.

## 완성 범위

| 구분 | v1.0 완료 결과 |
| --- | --- |
| 기본 방송 | 선택적으로 YouTube 채팅을 받아 한국어 답변을 생성하고 음성 출력 |
| 캐릭터 | 음성에 맞는 입 움직임, 허용된 표정, OBS 화면·음성·자막 동시 출력 |
| 운영 제어 | 운영자의 즉시 중단·일시 정지·음소거·재개, 시청자·모델의 운영 명령 실행 차단 |
| 기억·마이크 | 허용 정보의 SQLite 저장·조회·삭제와 마이크 STT; 각각 비활성화 가능 |
| 장애 대응 | 외부 서버·인증·오디오·파일 오류에 대한 명시적인 중단·기능 축소·복구 |
| 배포 | 다른 개발자가 문서만으로 설치·실행·검증하고 이전 버전 복구 |

벡터 DB, 모델 미세조정, 다중 방송 플랫폼, 게임 자동 조작, 무인 24시간 방송은 후속 확장이다. 거대한 Router·RAG·Agent 구조를 선행 도입하지 않는다. 선택 기능은 구현·검증이 필수이지만 매 실행에서 켤 필요는 없다.

원래 작업 폴더에서 합의한 `docs/v1-completion.md`와 README·skill.md 수정은 아직 미커밋 상태이므로 이 worktree에는 포함되지 않는다. 이 문서는 사용자 지정 v1.0 범위를 독립적으로 기록하며, 기준 커밋의 초기 단계 설명보다 이번 릴리스 범위에 우선한다. 향후 문서 통합 시 기존 변경을 보존한다.

## 작업 공간과 기준점

- 원본: `../Project-virtual-AI`, 브랜치 `feat/youtube-chat`. 기존 수정 파일을 그대로 유지한다.
- 검증 공간: `../Project-virtual-AI-readiness`, 브랜치 `work/release-readiness`.
- `git fetch origin` 후 `origin/feat/youtube-chat`과 로컬 HEAD가 위 전체 SHA와 같은 것을 확인하고 worktree를 생성했다.
- 이번 검증 중 소스·설정 예시·잠금 파일은 수정하지 않았다. 새 `.venv`에서 잠금 설치했다.
- `configs/app.yaml`은 새 worktree에 없다. 인증 토큰·모델·참조 음성·원본 로컬 설정은 복사하거나 덮어쓰지 않았다. mock 검증에는 필요하지 않다.
- 실제 검증 단계에서 운영자가 필요한 로컬 설정과 사용 권한이 있는 자산을 별도로 준비한다. 파일이 이미 있으면 보존하고, 활성 기능별로 설정을 확인한다. 비밀값과 생성 음성·시청자 기록은 커밋하지 않는다.
- 원본 폴더와 worktree를 혼동하지 않도록 실행 전 `git rev-parse --show-toplevel`과 `git rev-parse HEAD`를 확인한다. 기준 SHA를 움직이는 원격 브랜치 이름으로 대체하지 않는다.

## 단계별 담당과 통과 조건

담당은 역할 기준이다. 개발 담당은 코드·자동 검사·문서, 운영자는 장치·계정 준비와 직접 청취·화면 확인, 검토자는 통합·배포 판정을 맡는다. 별도 개발자는 설치 재현을 담당하며 인원 배정은 해당 단계 시작 시 기록한다.

| 순서 | 작업 | 담당 | 통과 조건 |
| --- | --- | --- | --- |
| 1 | 기준 버전·작업 공간 고정 | 개발 담당 | 같은 SHA에서 잠금 설치·pytest·Ruff·mock 성공, 기능별 실제 검증 대기 목록 작성 |
| 2 | 실제 음성 | 운영자 + 개발 담당 | 고정 문장·LLM 답변 직접 청취, 잡음·잘림·겹침·중지 후 무음·다음 질문·종료 후 재실행 확인 |
| 3 | VTS·립싱크·OBS | 운영자 + 개발 담당 | 인증·허용 표정·입 움직임·중단 복귀를 실제 모델로 확인하고 화면·음성·자막 로컬 녹화 검토 |

| 5 | 운영 제어·시작 점검 | 개발 담당 + 운영자 | 중단·일시 정지·음소거·재개와 권한 경계, 활성 기능 준비 상태·실패 처리 검증 |

## 통합 시 참고할 커밋 관계

이번 fetch와 로컬 이력에서 확인한 순서는 다음과 같다. PR 번호·Draft 여부·원격 CI·병합 가능 상태는 이번에 조회하지 않았다. 이 목록은 병합 승인이 아니다.

```text
origin/main e79b40b
→ feat/tts-client de102bc
→ feat/voice-pipeline 92061b0
→ fix/koboldcpp-server-abort 13fb4b1
→ feat/vts-client e806e1f
→ feat/vts-expression-pipeline c82ab11
→ feat/vts-lipsync 5f3022b
→ feat/obs-subtitles c2d1ca5
→ feat/youtube-chat 04564f1
```

음성의 직접 청취와 VTS 실제 모델 검증 전 병합 보류라는 기존 기준을 유지한다. 자동 성공만으로 다음 실제 검증을 완료 처리하지 않는다. 다음 작업은 2단계 실제 음성 검증이다.
