# 프로젝트 현재 상태

기준일: 2026-09-26. 현재 운영 보완은 [15개 제안 반영표](project-improvements-2026-09-26.md)를 따른다.
날짜가 있는 이전 문서는 당시 실행 증거다. 최신 소스/설정과 동일한 실행이라고 간주하지 않는다.
최신 Windows Python 3.11·3.14에서 각각 750개와 하위 검사 9개 통과. Linux 배포 ZIP도 746개 통과·4개 건너뜀을 확인했다.
실제 입력 검증은 사용자 일정에 따라 15시 이후 준비되었을 때 진행하며 자동 녹음·송출하지 않는다.

| 영역 | 현재 상태 | 남은 확인 |
|---|---|---|
| LLM/RAG/기억/대화 | 선택 기능 구현 및 실제 모델의 제한된 회귀 확인 | 다양한 한국어·독립 질문·사람 평가 |
| 음성/VTS/OBS | 실제 설치·연결·중단·재개·저장 녹화 확인, 기존 음성 직접 청취 정상 | 최종 방송 자산·새 변경의 청취/화면 수용 |
| 운영 보완 | 모드, 전달 상태, 운영 통계, 로컬 운영 UI, 예열, OBS 갱신, 세션 증거 구현 | UI 시각 검증, 실제 사용자 운영 수용 |
| 채팅 | 수신 어댑터와 제한 정책 구현, 치지직 실제 구독 확인 | 실제 시청자 메시지에서 최종 음성까지 반복 검증 |
| STT | 엔진·small 설치, 한국어 파일 2회·무음·취소·시간 초과 정리 통과 | 실제 한국어 마이크·방 소음·재유입 검사 |
| 안정성 | 혼합 부하 약 32분: 완료율 91.75%·첫 음성 p95 16.80초로 목표 미달. 수정 후 5분도 VTS 종료로 전체 실패(음성 15/15 완료). VTS 재연결은 복구 확인 | VTS 연결 유지, 지연 개선, 수정 후 장시간·2시간 운용 합격 |
| 배포 | RAG 샘플 누락 수정 후 Linux 배포 ZIP 설치·회귀 통과 | 새 PC 재현, 최종 커밋 CI, 최종 자산 권한, 릴리스 승인 |

**v1.0.0 승인은 보류 상태다.** 새 기능 반영과 공개 방송 수용은 구분한다.
기억과 STT는 선택적으로 끌 수 있어도 기존 v1.0 검증 범위에 남는다.

## 사용 시작

외부 엔진·OBS·VTS를 준비하고 루트 `start.cmd`를 실행한다. 로컬 리허설이며 외부 채팅은 비활성이다.
터미널에 표시되는 운영 화면 URL을 브라우저에서 연다. `/quit`으로 종료하면 지정한 세션 보고서를 저장한다.
이 PC의 로컬 설정/인증 파일은 Git 제외다. 다른 PC에서는 [운영 안내](operator-guide.md)와
[외부 엔진 구성](backends.md)을 먼저 따른다.
