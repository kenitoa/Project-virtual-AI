## 이번 실행

- 의존성: `python -m uv sync --locked` 통과. 새 의존성·DB 스키마 마이그레이션 없음.
- 새 대화 테스트 **24개**: 주제·사용자 격리·TTL, 명시적 정정, 응답 선택/묶기, 네트워크 지연 반응 제외, 어미 변환, 실제 프롬프트 예산, 근거 선택 계약, 기억 쿨다운/권한 철회, 중지, 차단된 출력의 기록 방지.
- 기존 RAG 합성 평가: **100/100**, 검색 대상 **45/45**, 키워드 기준선 **22/30**. 실제 LLM 호출 없음.
- 다중 턴 합성 평가: **16/16**, 모드 `scripted_contract`. 첫 실행에서 큐 단계 중복 거절을 대화 단계 건너뛰기로 잘못 집계한 부분을 고친 후 재실행했다.
- `.local/rag-evaluation-dialogue-20260926.json`, `.local/dialogue-evaluation-20260926-final.json`은 Git 제외 최종 보고서다.
- 기본 `http://127.0.0.1:5001/v1/models` 읽기 확인은 연결 시간 초과. 모델 서버 시작·가중치 변경·다운로드는 수행하지 않았다.

최종 코드 전체 회귀: `python -m uv run --locked pytest -q` → **700 passed, 9 subtests passed**, 61.70초.
`ruff check .` 및 `ruff format --check .` 통과(154개 파일), `git diff --check` 공백 오류 없음.
`--backend mock --local-only --dialogue --once "안녕"` 실제 CLI 실행에서 “안녕하세요!” 출력·정상 종료를 확인했다.
최종 다중 턴 합성 평가의 턴 시간은 중앙값 약 45ms / p95 약 109ms다. 로컬 가짜 LLM을 포함한 제어 흐름 시간이며 실제 생성 속도가 아니다.

## 확인하지 못한 항목

실제 모델의 source_ids 계약 준수율·관련 자료 선택, 자유 대화의 자연스러움·복합 질문 누락,
실제 엔진 지연·GPU 경합·장시간 실행, 스피커/헤드폰 청취, VTS·OBS·실제 방송 수용은 미확인이다.
합성 테스트 수치는 모델 품질이나 방송 준비 완료의 증거로 사용하지 않는다.

RAG·대화 확장은 기본 비활성이다. `--dialogue`로 대화 제어만 켤 수 있으며,
기억 저장/공개 권한은 별도로 설정한다. 운영 방법과 조건부 후속 작업은 [구현 문서](dialogue-development.md)에 있다.
