## 확정 시 기록할 항목

음성은 엔진과 모델을 구분한다. GPT·SoVITS 각 파일명/해시/출처 revision, 참조 WAV 해시·길이·언어, 정확한 전사문, 사용 허락 근거와 허용 범위를 기록한다. 전사문·개인 경로·자산 파일·권한 증빙 원본은 Git 제외 영역에 보관하고, 다른 개발자에게 허용된 방식으로 전달한다. 공개 문서에는 비밀값 없는 식별 정보만 남긴다.

Live2D는 모델 파일 식별자·해시, VTS 버전·모델 ID, 기본 표정과 `happy`·`sad`의 실제 `ToggleExpression` 핫키 ID, 표정 파일 매핑, **VTS 입력 파라미터** 이름과 0~1 지원 범위를 고정한다. Live2D 출력 파라미터 이름을 임의로 VTS 입력 이름으로 사용하지 않는다. 인증 토큰은 장치별로 발급하고 공유하지 않는다. [VTS](vts.md)와 [립싱크](lipsync.md)의 실제 모델 검증 전까지 매핑은 미확정이다.

## 오디오와 OBS

이번 장치 열거에서 확인한 후보:

- 기존 로컬 출력 설정: 장치 3, `스피커(2- Realtek(R) Audio)` / MME. 실제 청취·최종 선택은 미확인.
- 같은 출력의 WASAPI 항목: 장치 11. 호스트 API 변경도 검증 구성 변경이므로 임의 전환하지 않는다.
- 마이크 후보: 장치 12, `마이크 배열(2- 디지털 마이크용 인텔® 스마트 사운드 기술)` / Windows WASAPI. 녹음·선택은 미확인.
- OBS 계획: 앱 재생을 선택한 출력으로 보내고 OBS에서 해당 출력의 오디오를 한 경로로만 캡처한다. 캐릭터 화면과 파일 자막은 [OBS 절차](obs-local-recording.md)를 따른다. 실제 OBS 소스·버전·녹화 결과는 미확정.

장치 번호는 PC와 재연결에 따라 달라질 수 있다. 두 개발자는 장치 이름·호스트 API·출력/입력 역할을 기록하고 각 PC의 번호를 다시 조회한다. 현재 마이크 STT 기능은 구현 전이므로 마이크 선택이 STT 검증 완료를 뜻하지 않는다.
